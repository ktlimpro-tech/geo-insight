# Geo Insight

소상공인 창업, 상권 분석, 지역 시장 조사를 위한 **인구 통계 및 상권 데이터 분석 대시보드**입니다. 
전국 시도, 시군구, 행정동 단위의 인구 현황과 상권 데이터를 통합하여 다양한 관점의 지역 분석 정보를 제공합니다.

## 주요 기능

### 인구 분석

- 연령별 인구 구조 분석
- 성별 인구 분석
- 인구 피라미드 시각화
- 인근 지역 인구 비교
- 전국 연령대별 인구 통계

### 상권 분석

- 업종별 점포 현황 분석
- 대분류 / 중분류 / 소분류 업종 분석
- 업종 비율 시각화
- 지도 기반 상가 위치 조회
- 상가 목록 검색

### 인사이트

- 동네 한눈에 보기
- 인근 지역 비교
- 전국 인구 동태 분석
- 혼인·이혼 통계 분석
- 전국 인기 업종 Top 30
- 연령대별 인구 최다/최소 지역 분석

## 데이터 출처

- 행정안전부 주민등록 인구통계
- KOSIS 국가통계포털
- 소상공인 상권정보 데이터 (2025년 기준)
- source: `data.go.kr > 소상공인시장진흥공단_상가(상권)정보_20251030`
  - data url: https://www.data.go.kr/data/15083033/fileData.do
  - 2025년 전국 소상공인 상가(상권) 정보: 시도/시군구/행정동, 상권업종{대분류/중분류/소분류} 필터 선택 및 시각화
  - 이 앱은 간단한 테스트용 프로젝트입니다.
